# Gallery

Demo of the Area512Widget UI parts for Area512/Cardputer.
Six tabs: `PARTS`, `TABLE`, `CHART`, `LIST`, `TEXT`, `MODAL`.

## Controls

- `LEFT` / `RIGHT`: previous / next tab
- `q`: quit

## PARTS tab

- `j` / `k` (or `UP` / `DOWN`): move the focus
- `space` / Enter: change the focused part
- `h` / `l`: change the spinner value (when the spinner is focused)

## CHART tab

- `h` / `l`: shift the sample values down / up

## LIST tab

- `j` / `k` (or `UP` / `DOWN`): move the selection
- `m`: mark / unmark the selected row
- `x`: clear the list

## TEXT tab

- `j` / `k` (or `UP` / `DOWN`): scroll the text view

## MODAL tab

- `space` / Enter: open the modal menu, then pick
  input / number / confirm / dialog / menu / alert

## Notes

- The `TABLE` tab has no keys; it only shows the table and field parts.
