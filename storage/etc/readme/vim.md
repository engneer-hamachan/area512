# Vim

Tiny vim for Area512/Cardputer.

## Controls

- `i` / `a` / `I` / `A` / `o` / `O`: insert mode (Esc returns to normal mode)
- `h` / `j` / `k` / `l`: move the cursor
- `w` / `b` / `e`, `0` / `^` / `$`: move by word / within the line
- `gg` / `G`: first / last line
- `Ctrl-F` / `Ctrl-B`, `Ctrl-D` / `Ctrl-U`: page / half page
- `x`, `dd`, `D`: delete a character / line / to line end
- `yy`, `p` / `P`: copy a line, paste
- `v` / `V`: visual mode
- `/` then `n` / `N`: search
- `K`: hover or diagnostic at the cursor
- `Ctrl-N` (insert mode): completion
- `:w` / `:q` / `:q!` / `:wq`: save / quit / quit without saving / save and quit
